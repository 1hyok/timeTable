# 시간표·학습 계획 프로그램

C++로 시간표와 학습 계획을 다루는 프로젝트입니다. 소스는 `src/`, 헤더는 `include/`, 데이터는 `data/`에 있습니다.

## 대상과 구성

수업 프로젝트를 살펴보거나 CMake 기반 C++ 프로그램의 구조를 참고하려는 사람을 위한 학습 기록입니다.

## 빌드

필요 환경은 CMake 3.10 이상과 C++20 컴파일러입니다.

```sh
cmake -S . -B build
cmake --build build
./build/timeTable
```
